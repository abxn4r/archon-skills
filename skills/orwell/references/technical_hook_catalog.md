# TECHNICAL HOOK CATALOG & PLAYBOOK
*Archon High-Converting Hook Formats for Builders & Engineers -- Orwell Advisor*

---

## 1. THE CONTRARIAN POST-MORTEM
- **Structure**: Challenge an accepted industry standard by demonstrating the operational tax it extracted.
- **Template**: "We ripped out [popular tool / framework / library] after [time period]. Here is the 12-line Python script that replaced it and saved us [metric]."
- **Proof Requirement**: Show the actual before/after code or benchmark.

---

## 2. VULNERABILITY-TO-FRAMEWORK
- **Structure**: Acknowledge an invisible delay tactic or design mistake, then articulate the invariant rule that cured it.
- **Template**: "I spent two weeks writing spec docs for features that didn't exist. Here is the 'Artifacts Before Docs' rule that eliminated our invisible procrastination."
- **Tone**: High self-awareness, zero defensive posturing.

---

## 3. SYSTEM ARCHITECTURE BLUEPRINT
- **Structure**: Visual breakdown of an end-to-end subsystem that solves a hard engineering problem simply.
- **Template**: "How we built a cross-session compounding memory system using strictly the Python Standard Library (no vector DB, no pip dependencies)."
- **Engagement Driver**: Engineers bookmark blueprints for future reference.

---

## 4. THE EXTREME CONSTRAINT EXPERIMENT
- **Structure**: Show what happens when a standard resource is completely withheld.
- **Template**: "What happens when you build a full agent harness with zero third-party dependencies? Lessons from 10,000 CLI executions."
